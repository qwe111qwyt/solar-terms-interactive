# 节序循时 · 二十四节气沉浸式交互

以中国传统二十四节气为主题的沉浸式交互网页作品。通过卷轴叙事、物候插画、本草器物与场景特效，呈现四季流转与节气意蕴，适配手机/平板竖屏（9:16）体验。

## 在线体验

- GitHub Pages：<https://qwe111qwyt.github.io/solar-terms-interactive/>

## 本地体验

方式一：直接双击 `index.html` 在浏览器中打开。

方式二：本地启动静态服务器（推荐，避免个别浏览器限制）：

```bash
npx serve .
# 或
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 内容与交互

- 二十四节气全景：立春至大寒，按四时流转切换场景
- 卷轴过场与物候叙事：各节气含物候、花信风、本草、器物图文
- 场景特效：飞雪、烟雨、萤火、河灯、蝉鸣等动态效果（WebP 序列 + 动效合成）
- 竖屏沉浸式舞台：9:16 满屏布局，支持触控交互

## 技术栈

- 原生 HTML / CSS / JavaScript（无框架，数据内联于 HTML）
- GSAP 3.12.5（CDN 引入）驱动动效
- WebP 图片素材（`webp/` 目录，共 270 张）

## 目录结构

```
deploy/
├── index.html      # 单页应用入口（数据内联）
└── webp/           # 场景、物候、特效等全部图片素材
```
